# Complete Auto Repair

Responsive static website for Complete Auto Repair in Irving, Texas.

- Phone: (408) 242-4903
- Address: 310 E Pioneer Dr, Irving, TX 75061
- Hours: 9:00 AM–6:00 PM. Open days are not yet specified; the website asks visitors to call to confirm.

## Preview

Open `index.html` in a browser, or run `python -m http.server 8080` from this folder and visit http://localhost:8080.

No installation or build is required. The artwork is inline SVG and CSS, with system fonts and no external asset dependencies. Click-to-call and Google Maps directions are live links. Service categories invite visitors to confirm availability by phone; there is no appointment submission backend.

The existing `CNAME` is preserved for `completeautorepairtx.com`. GitHub Pages hosting and DNS must be configured separately.
